ARXML Studio v0.3.0 新增独立后端服务和 Docker 部署，同时保留带 Vue 页面的单文件程序。

### 新增功能

- 纯后端 `arxml-server`：无需 Docker、Go、Node 或 Python，解压后可直接运行。
- 完整程序 `arxml-studio`：内嵌 Vue 页面，保留本地服务浏览、A/B 对比和配置导出。
- 可配置监听地址、Bearer Token、CORS Origin 和 API 并发限制。
- 健康检查、请求日志、SIGTERM 优雅退出，以及直接返回 ZIP 的 `/api/export/zip`。
- Dockerfile、Compose 和不依赖 Docker Hub 基础镜像的离线构建入口。
- 推送版本标签后，由 GitHub Actions 自动测试、构建并发布 Release。

### 下载选择

每个平台均提供两种安装包：`arxml-studio_*` 是带界面的完整程序；`arxml-server_*` 是纯 HTTP API 后端。

| 平台 | 文件后缀 |
| --- | --- |
| macOS Apple Silicon | `_darwin_arm64.tar.gz` |
| macOS Intel | `_darwin_amd64.tar.gz` |
| Linux x86-64 | `_linux_amd64.tar.gz` |
| Linux ARM64 | `_linux_arm64.tar.gz` |
| Windows x86-64 | `_windows_amd64.zip` |

共 10 个安装包，附有 README、后端 API 文档和示例配置；运行时只需要其中的可执行文件。下载后可使用 `SHA256SUMS.txt` 校验完整性。

### 裸程序启动

完整程序：`./arxml-studio`，浏览器打开 `http://127.0.0.1:8765`。

纯后端：`./arxml-server --listen 127.0.0.1:8080`，健康检查为 `http://127.0.0.1:8080/health`；Windows 使用相应的 `.exe` 文件。

对外监听 `0.0.0.0:8080` 时，需要设置至少 32 字符的 `ARXML_API_TOKEN`，API 请求携带 `Authorization: Bearer <token>`。服务无状态，不包含账号系统、数据库或文件历史；详细配置见安装包中的 `docs/backend.md`。

### 验证与限制

完整与 headless 模式均通过 Go 测试、竞态检测、go vet；Vue 通过 TypeScript 检查与生产构建。macOS ARM64 裸程序、Linux ARM64 Docker 容器已验证健康检查、鉴权、解析、对比、ZIP 导出与正常停止。其余平台完成交叉编译，尚未全部实机验证。

macOS 安装包未进行 Developer ID 签名或公证。复杂 ARXML 类型、跨文件引用合并和完整序列化约束仍有限制；CommonAPI 生成文件尚未完成目标工具链及 ECU 通信验证。
