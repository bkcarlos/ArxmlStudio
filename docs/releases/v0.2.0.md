ARXML Studio v0.2.0 是 Go + Vue 版本的首个公开发布版。

### 功能

- 浏览 ARXML 服务、methods、events、fields、参数、类型引用及 SOME/IP 部署。
- 加载 A/B 两份文件，按完整路径比较接口、部署与数据类型，定位具体属性变化。
- 选择文件、服务和 Server / Stub 或 Client / Proxy 角色，导出 CommonAPI `.fidl`、`.fdepl` 与 vsomeip JSON。
- Go 内嵌 Vue 页面和演示文件，运行时无需 Python、Node、Go 或额外静态资源。
- 同时支持浏览器和命令行使用。

### 下载与启动

| 系统 | 安装包 |
| --- | --- |
| macOS Apple Silicon | `arxml-studio_v0.2.0_darwin_arm64.tar.gz` |
| macOS Intel | `arxml-studio_v0.2.0_darwin_amd64.tar.gz` |
| Linux x86-64 | `arxml-studio_v0.2.0_linux_amd64.tar.gz` |
| Linux ARM64 | `arxml-studio_v0.2.0_linux_arm64.tar.gz` |
| Windows x86-64 | `arxml-studio_v0.2.0_windows_amd64.zip` |

解压后运行 `./arxml-studio`（Windows 为 `arxml-studio.exe`），浏览器访问 `http://127.0.0.1:8765`。端口被占用时加 `--port 8766`。安装包附带示例 ARXML、导出参数、使用说明和第三方许可，实际运行只需可执行文件。

`SHA256SUMS.txt` 提供安装包校验值。macOS 二进制尚未进行 Developer ID 签名或公证。

### 验证与限制

- 通过 Go 单元/API 测试、竞态检测、`go vet` 和 Vue/TypeScript 构建检查。
- macOS ARM64 已验证独立目录运行、内嵌页面、双文件对比与双方配置导出。
- 其余平台通过交叉编译，尚未在各平台实机验证。
- 复杂类型、跨文件引用合并和完整 AUTOSAR 序列化规则尚不支持；缺失或不支持的配置会提示错误。
- 生成的 CommonAPI 文件尚未通过实际工具链编译或 ECU 通信验证。
